# 04: 记牌核心 + 剩余牌库面板（M1）

**What to build:** 记牌核心（纯函数）：输入卡牌池 + 消耗牌事件流，输出剩余牌库清单与每张未现牌的出现概率（剩余牌库 = 卡牌池 − 消耗牌，对手手牌与真实牌库按均匀隐含分布处理）；面板实时展示剩余牌库清单、按类型汇总、关键牌概率 Top 列表。对局中每有事件流更新，面板实时刷新。

**Blocked by:** 01 工程脚手架 + 面板空壳、02 卡牌数据库 v1、03 日志解析器

**Status:** in-progress(代码完成,待真实对局页面目检)

- [x] 记牌核心为纯函数，有回放 fixture 测试（给定事件流断言剩余牌库与概率）
- [x] 我的手牌视为已知区域，从推算的未知池中剔除
- [ ] 偷窃等跨越已知/未知边界的事件会即时更新推算 —— 核心模型已支持(已知集合增删),但日志模式待真实样本出现后补充
- [ ] 面板显示剩余牌库清单与概率，随对局事件实时更新 —— 已实现(MutationObserver + 防抖),待真实页面目检
- [ ] 中途刷新页面后从日志重建，面板状态不丢失 —— 已实现(每次全量解析 #logs),待真实页面目检
- [x] 卡牌名显示中文名 + 英文原名
