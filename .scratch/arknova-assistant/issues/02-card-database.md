# 02: 卡牌数据库 v1

**What to build:** 基础版 + 海洋世界扩展全部卡牌的结构化 JSON 数据集：每张牌含英文原名（稳定 key）、中文名、类型、费用、标签、效果文本、吸引力/保护点等字段；提供按 key 查询的接口；以 GitHub 社区开源数据集为底，人工对照牌表校对补齐 Marine Worlds。仅供个人使用，不二次分发。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 基础版与海洋世界卡牌齐全(数量与官方牌表一致)
- [x] 每张牌必填字段完整,唯一稳定 key(采用 BGA 官方 id,如 `A401_Cheetah`;官方编号在 bg/mw 变体间有 8 处重复,不能当 key)
- [x] 有完整性校验测试(数量、必填字段、key 唯一性、中文名覆盖、日志样本反查)
- [x] 数据独立于代码,未来加新扩展不改查询接口(cards.json/maps.json 独立文件)
